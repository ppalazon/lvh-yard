# Support

- To learn how to install and use LVH Yard, read the
  [user guide](docs/user-guide.md).
- To ask a question or report a bug, open a
  [GitHub issue](https://github.com/ppalazon/lvh-yard/issues).
- To report a security problem, follow [SECURITY.md](SECURITY.md). Do not open
  an issue.

When you report a bug, give the output of `lvh-yard --version` and
`lvh-yard status`, and your operating system.
